# ChatGPT Chat Manager（Edge 聊天白名单助手）

**版本：v0.2.0（安全预览版）** · **技术栈：Manifest V3 / JavaScript / HTML / CSS** · **无第三方依赖、无需构建**

用于在 ChatGPT 网页中识别**当前已加载的聊天**，通过网页拖动框选、关键词或手动勾选创建本地白名单，并预览候选与导出 CSV。**本版本不会删除、归档任何聊天。**

> ⚠️ 本项目尚不能识别账号内全部历史聊天；不要把“候选”当作全账号可删除清单。项目识别属于启发式判断，不能保证覆盖所有项目聊天。

## 1. 功能状态

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 读取当前已加载的聊天链接 | ✅ | 识别页面中具有 `/c/<id>` 格式的可见链接 |
| 网页实时拖动框选加入白名单 | ✅ | 选择矩形与聊天链接重叠面积至少 30% 时保护 |
| 关键词保护 | ✅ | 逗号、中文逗号或换行分隔；不区分英文大小写 |
| 手动勾选保护 | ✅ | 基于聊天 ID，避免同名标题混淆 |
| CSV 导出 | ✅ | 导出当前扫描清单和保护来源 |
| 本地保存设置 | ✅ | `chrome.storage.local`，不发送到外部服务 |
| 项目聊天保护 | ⚠️ | 根据 URL / 页面标记做启发式识别；**不能保证完整** |
| 扫描账号全部历史、跨工作区 | ❌ | 页面未加载内容不在扫描范围 |
| 上传截图 + OCR 识别标题 | ❌ | 当前“框选”是直接在网页上拖动，不是图片识别 |
| 自动批量删除 / 归档 | ❌ | 安全预览版不执行变更 |

## 3. 本地 VS Code 打开与安装

1. 解压项目 ZIP，在 **VS Code → 文件 → 打开文件夹** 中选择 `ChatGPT_Chat_Manager`。
2. Edge 地址栏访问 `edge://extensions/`，打开右侧或侧边的 **开发人员模式**。
3. 选择 **加载解压缩的扩展**，指向 **`ChatGPT_Chat_Manager/extension/`**（即有 `manifest.json` 的目录）。
4. 打开或刷新 `https://chatgpt.com/`，单击工具栏里的扩展图标。

修改 `extension/` 代码后，在 `edge://extensions/` 找到插件并点击**重新加载**，随后刷新 ChatGPT 页面。没有构建步骤。

## 4. 使用说明

### 4.1 扫描与保护

1. 在 ChatGPT 页面打开扩展，点击 **扫描当前列表**。仅列出当前已加载且有聊天链接的条目。
2. 要保护部分聊天，点击 **在页面拖动框选保留**，弹窗自动关闭；在左侧列表按住左键拖动矩形，松开完成。按 **Esc** 退出而不保存。**一次框选仅作用于当前屏幕内相交的条目**。
3. 再次打开扩展，可输入如 `MongoDB, Kafka, Kubernetes` 并点击 **保存关键词**，匹配标题的聊天会被标记为保护。
4. 也可单独勾选聊天强制保留；取消勾选只移除**手动白名单**，若仍命中关键词或项目规则，仍显示“保留”。
5. 点击 **导出清单 CSV** 核对当前扫描结果。可以先用 Excel 打开检查，再决定后续手工处理。

### 4.2 判断结果

- **保留**：聊天 ID 在手动白名单中，或标题匹配关键词，或页面启发式识别为项目聊天。
- **候选**：在当前扫描结果中没有命中上述规则；**不是已验证的删除对象**。
- **已扫描数量**：仅本次读取的页面已加载聊天数；滚动后重新扫描会**替换**此前扫描结果，不会自动汇总所有历史。
- 手动白名单不会因重新扫描丢失，除非点击 **清空手动白名单** 并确认。

## 5. 核心实现逻辑

```text
Edge 弹窗 popup.js
  ├─ chrome.tabs.sendMessage('SCAN') → content.js 扫描可见 /c/<id> 链接
  ├─ chrome.tabs.sendMessage('FRAME') → content.js 叠加框选层
  │                                    └─ 命中条目 → chrome.storage.local.whitelist
  ├─ 输入关键词 / 手动勾选 → chrome.storage.local
  └─ 本地合并保护规则 → 显示保留/候选 → 导出 CSV
```

匹配优先级：**手动框选或勾选 > 关键词匹配 > 项目启发式保护 > 候选**。保护条件按逻辑“或”计算；命中任意一项即保留。

技术细节见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 6. 调试与验证

- **弹窗逻辑**：右键扩展弹窗 → **检查**，查看 Console。
- **页面脚本**：在 ChatGPT 页面按 **F12**，查看 Console；修改后先重新加载扩展，再刷新页面。

## 7. 安全和已知限制

- 不读取 Cookie、访问令牌，不调用私有接口，不上传聊天内容。
- `chrome.storage.local` **未按 ChatGPT 账号或工作区隔离**；多账号建议使用独立 Edge 浏览器配置文件。
- 页面 DOM 结构可能变化，导致列表扫描、项目识别或框选失效；遇到异常请停止操作并检查页面结构。
- 当前只识别**可见且已加载的** `/c/<id>` 链接，历史、归档和其他工作区可能被遗漏。
- 框选通过聊天链接的矩形相交面积计算，滚动容器边缘、缩放、重叠元素可能影响选择效果，务必重新打开弹窗检查保护结果。
- 删除聊天属于不可逆操作；如后续添加批量删除，必须先解决完整清单、账号隔离、项目保护准确性与二次确认等问题。

## 8. 后续开发建议

1. **账号与工作区隔离**：按明确身份建立不同白名单存储空间。
2. **独立侧边栏 + 增量扫描**：避免弹窗关闭和列表按需加载带来的不完整数据问题。
3. **截图 OCR**：上传截图后本地识别标题，遇到同名聊天先二次确认 ID，不允许仅靠文本自动删除。
4. **操作执行模块**：默认归档优先；批量删除需完整候选预览、明确二次确认、可中止、逐条日志及失败处理。
