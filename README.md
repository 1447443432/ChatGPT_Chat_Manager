# ChatGPT 聊天白名单助手

**正式版 1.0.0｜Chrome / Edge｜Manifest V3**

扫描 ChatGPT 当前已加载的聊天，按白名单、关键词和项目规则保护内容；支持搜索、截图识别、CSV 导出，以及核对后逐条删除。

## 安装

1. 打开 `edge://extensions/` 或 `chrome://extensions/`，启用“开发人员模式”。
2. 选择“加载解压缩的扩展”，载入仓库中的 `extension/` 目录。
3. 打开或刷新 ChatGPT 页面，再点击扩展图标。

更新代码后，在扩展管理页重新加载扩展并刷新 ChatGPT。

## 使用

- 扩展打开时自动扫描；“重新获取”会清理扫描缓存并重新读取当前页面。滚动侧栏可继续发现已加载的聊天。
- 在“聊天”页搜索标题或 ID；在“项目”页按项目批量保护或展开后单独选择聊天。
- 截图识别在本地运行。匹配结果需核对；唯一匹配会自动选中，多条匹配需手动选择。
- 删除前在“待删除”页核对名单并勾选确认。可删除选中项或未受保护的候选项；每条都会重新校验，异常时停止。

## 范围与隐私

- 扫描范围是当前页面已加载、侧栏可定位的聊天，不代表账号全部历史；项目识别依赖页面信息，可能不完整。
- 白名单、关键词、项目保护规则和设置保存在浏览器本地；OCR 在本地运行。数据不按 ChatGPT 账号隔离，多账号建议使用不同浏览器配置文件。
- 删除通过当前 ChatGPT 页面会话请求站点接口，令牌只在内存中临时使用，不保存、不发送到第三方。接口未公开，站点变更可能导致删除失败。
- 删除不可恢复。请逐项核对标题与范围；不确定时停止并重新扫描。
