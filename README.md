# ChatGPT Chat Manager（Chrome / Edge 聊天白名单助手）

**版本：v0.0.4.20261030128** · **技术栈：Manifest V3 / JavaScript / HTML / CSS** · **内置离线 OCR、无需构建**

版本规则：较大功能变更递增前三段（例如 `0.0.4`）；小修订仅更新构建号。浏览器要求 `manifest.version` 的每段数字不超过 65535，因此扩展使用 `0.0.4.14` 做更新比较，界面通过 `version_name` 显示完整日期构建号 `0.0.4.20261030128`。

用于在 ChatGPT 网页中识别**当前已加载的聊天**，在扩展弹窗内通过关键词、手动勾选或截图识别创建本地保护清单。可预览候选、指定少量聊天删除、导出 CSV，并在明确确认后逐条执行。

> ⚠️ 本项目尚不能识别账号内全部历史聊天；不要把“候选”当作全账号可删除清单。项目识别属于启发式判断，不能保证覆盖所有项目聊天。

## 1. 功能状态

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 清缓存并重新获取 | ✅ | 每次丢弃旧扫描结果，重新滚动当前页面列表并累积已加载的 `/c/<id>` 聊天及项目链接；白名单和规则保留 |
| 保护清单 | ✅ | 汇总本次扫描中受手动白名单、关键词或项目规则保护的聊天，并标明来源；手动白名单中未扫描到的记录仍显示 |
| 聊天列表分页 | ✅ | 默认每页 10 条；可输入每页条数、指定页，或用首页／上一页／下一页／末页切换 |
| 关键词保护 | ✅ | 逗号、中文逗号或换行分隔；不区分英文大小写 |
| 手动勾选保护 | ✅ | 基于聊天 ID，避免同名标题混淆 |
| CSV 导出 | ✅ | 导出当前扫描清单、保护来源和指定待删除状态 |
| 本地保存设置 | ✅ | `chrome.storage.local`，不发送到外部服务 |
| 项目聊天保护 | ⚠️ | 项目默认全选；可展开查看聊天、整组选中或取消，也可逐条调整；项目归属依赖页面识别，**不能保证完整** |
| 扫描账号全部历史、跨工作区 | ❌ | 页面未加载内容不在扫描范围 |
| 上传或粘贴截图 + 框选 OCR 识别标题 | ✅ | 本地识别；仅匹配本次扫描到的聊天；可加入手动白名单或待删除 |
| 指定删除 / 删除全部候选 | ⚠️ | 默认仅删除明确选中的聊天；也可切换为全部非保护候选。仅操作本次扫描、当前侧栏可定位的条目；界面变化时停止 |

### 从截图加入白名单

先在 ChatGPT 页面点击扩展弹窗中的“清缓存并重新获取”。切换到“截图”，直接按 Ctrl+V 粘贴图片，或选择图片文件。在预览图上拖动框选需要识别的区域，点击“识别截图”，逐行核对 OCR 文本与匹配的聊天，再选择“加入手动白名单”或“加入待删除”。OCR 在扩展本地运行，图片不会上传。切换到“保护清单”可查看所有保护来源。

截图只提供标题，不能可靠提供聊天 ID。因此只能从本次扫描到的聊天中选择；标题重复或未扫描到的聊天不会自动匹配。加入白名单时还会核对所选聊天 ID 与标题是否仍在本次扫描结果中。关键词保存后会显示本次扫描的命中数量；没有命中仍可保存，用于后续扫描。首次 OCR 需要加载扩展内的中英文模型，可能较慢。

### 保护整个项目

扫描后在“项目”页查看项目树。项目默认全选；展开后可逐条取消或选中聊天。项目勾选可对已识别的聊天整组选择或取消；部分选中时显示半选。若网页没有提供可识别的项目名，可在项目行内设置名称。打开 ChatGPT 项目主页再点“保护当前打开的项目”，也可补充关联该项目的聊天；此操作会使原删除清单失效，删除前需重新获取。扩展不能枚举未加载的聊天，也不能可靠判断其他页面上所有聊天的项目归属；已扫描数量不是项目聊天总数。

弹窗边缘和角落提供拖动缩放区，底部右侧有可见的斜纹手柄；也可用标题栏“放大 / 还原”快速切换。浏览器工具栏弹窗由浏览器管理，缩放在其允许的尺寸范围内进行（宽 380–780、高 360–600 像素）。

## 3. 本地 VS Code 打开与安装

1. 解压项目 ZIP，在 **VS Code → 文件 → 打开文件夹** 中选择 `ChatGPT_Chat_Manager`。
2. Edge 地址栏访问 `edge://extensions/`；Chrome 地址栏访问 `chrome://extensions/`。打开 **开发者模式**。
3. 选择 **加载解压缩的扩展**，指向 **`ChatGPT_Chat_Manager/extension/`**（即有 `manifest.json` 的目录）。
4. 打开或刷新 `https://chatgpt.com/`，单击工具栏里的扩展图标。

修改 `extension/` 代码后，在对应浏览器的扩展管理页找到插件并点击**重新加载**，随后刷新 ChatGPT 页面。没有构建步骤。

## 4. 使用说明

### 4.1 扫描与保护

1. 在 ChatGPT 页面打开扩展，插件会自动清理旧扫描缓存并获取当前页面的聊天与项目；顶部 **重新获取** 可手动刷新。
2. 在弹窗的“聊天”区域勾选要保留的聊天；在“项目”区域单独勾选要保护的项目；在“保护清单”区域查看所有被保护的聊天及来源。
3. 再次打开扩展，可输入如 `MongoDB, Kafka, Kubernetes` 并点击 **保存关键词**，匹配标题的聊天会被标记为保护。
4. 也可单独勾选聊天强制保留；取消勾选只移除**手动白名单**，若仍命中关键词或项目规则，仍显示“保留”。
5. 若只删除少量聊天，点击聊天行或项目子聊天行的 **待删除**，或用截图识别后点击 **加入待删除**。打开顶部 **待删除** 页签，选择“待删除名单”或“全部非保护候选”，核对明确列出的聊天，勾选“我已核对名单”后点击 **确认删除**。处理结束会自动重新获取列表，并汇报页面移除数、跳过数和剩余数量。

### 4.2 判断结果

- **保留**：聊天 ID 在手动白名单中，或标题匹配关键词，或命中已保护项目规则。
- **候选**：在当前扫描结果中没有命中上述规则；执行时再次核对白名单、关键词和项目规则，并要求目标仍在当前侧栏、标题及项目归属未变化。
- **指定删除**：可覆盖关键词和项目的默认保护，但不能覆盖手动白名单。手动白名单中的聊天须先移出白名单才能加入待删除。待删除选择只在当前弹窗保留，重新获取时清空。
- **已扫描数量**：仅本次读取的页面已加载聊天数；关闭弹窗后旧扫描结果不再用作删除依据，重新打开需重新获取。
- 手动白名单不会因重新扫描丢失，除非点击 **清空手动白名单** 并确认。

## 5. 核心实现逻辑

```text
Chrome / Edge 弹窗 popup.js
  ├─ chrome.tabs.sendMessage('SCAN') → content.js 扫描可见 /c/<id> 链接
  ├─ 弹窗勾选 / 截图识别 → chrome.storage.local.whitelist
  ├─ 输入关键词 / 手动勾选 → chrome.storage.local
  └─ 本地合并保护规则 → 显示保留/候选 → 导出 CSV / 逐条通过 ChatGPT 界面删除
```

保护条件按逻辑“或”计算：**手动白名单、关键词或项目规则命中任意一项即保留**。“删除全部非保护候选”遵守全部保护规则；“仅删除明确选中”可覆盖关键词和项目保护，手动白名单仍阻止删除。

技术细节见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

- **弹窗逻辑**：右键扩展弹窗 → **检查**，查看 Console。
- **页面脚本**：在 ChatGPT 页面按 **F12**，查看 Console；修改后先重新加载扩展，再刷新页面。

## 7. 安全和已知限制

- 不读取 Cookie、访问令牌，不调用私有接口，不上传聊天内容。
- `chrome.storage.local` **未按 ChatGPT 账号或工作区隔离**；多账号建议使用独立浏览器配置文件。
- 页面 DOM 结构可能变化，导致列表扫描或项目识别失效；遇到异常请停止操作并检查页面结构。
- 当前只识别**可见且已加载的** `/c/<id>` 链接，历史、归档和其他工作区可能被遗漏。
- 截图框选只裁剪图片识别区域；OCR 可能误读标题，加入白名单前务必核对匹配的聊天。
- 删除聊天无法恢复；删除操作仅针对本次扫描且当前侧栏能定位的聊天，不代表覆盖账号全部历史。页面结构变化、条目未加载或二次核对失败时会跳过或停止。请先检查项目树、候选列表及 CSV。

## 8. 后续开发建议

1. **账号与工作区隔离**：按明确身份建立不同白名单存储空间。
2. **独立侧边栏 + 增量扫描**：避免弹窗关闭和列表按需加载带来的不完整数据问题。
3. **截图 OCR 优化**：提升复杂布局和低清晰度截图的识别率；遇到同名聊天仍需核对 ID。
4. **操作执行模块**：完善逐条操作日志与恢复提示；持续适配 ChatGPT 网页菜单变化。
