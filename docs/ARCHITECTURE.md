# 架构与实现说明

## 模块

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | Chrome / Edge Manifest V3 配置、权限与 ChatGPT 页面脚本入口 |
| `content.js` | 扫描当前页面聊天和项目、框选页面条目、通过 ChatGPT 原生菜单逐条删除 |
| `popup.js` | 规则判断、项目树、分页、候选预览、确认与执行调度、CSV 导出 |
| `screenshot.js` | 弹窗内粘贴或上传图片，使用扩展自带 OCR 识别聊天标题 |
| `popup.html` / `style.css` | 弹窗界面与样式 |

## 数据与缓存

白名单、关键词、项目排除规则、单条项目聊天的覆盖规则和手动设置的项目名称保存在 `chrome.storage.local`。扫描得到的聊天和项目、待删除选择仅保留在本次打开的弹窗中。重新获取时清空待删除选择。打开弹窗或重新获取时，会清除旧版留下的 `scan`、`scanAt`、`projects`、`projectChats`、`projectChatDetails` 和 `protectedProjects` 缓存；白名单及用户设置保留。

插件当前未按 ChatGPT 账号或工作区隔离规则。使用多个账号时应使用不同浏览器配置文件。

## 扫描与保护

内容脚本遍历页面已加载的 `/c/<id>` 链接，尝试滚动聊天列表收集更多条目，按聊天 ID 去重。项目 ID 从 `/g/<project-id>/c/<chat-id>` 地址或页面 DOM 标记提取；项目名称从侧栏标记或项目链接提取。页面可能按需加载或虚拟化，因此扫描不能保证覆盖账号全部历史。

保护条件按逻辑“或”合并：聊天 ID 在手动白名单内、标题命中关键词、或项目规则保护此聊天。项目默认保护；用户可以整组取消，也可以为项目中的单条聊天覆盖项目规则。“保护清单”汇总展示这些来源。截图 OCR 只匹配本次扫描的真实标题，需要用户核对后才写入手动白名单或待删除选择。

## 删除流程

1. 用户清除旧扫描缓存并重新获取当前页面列表。内容脚本保留本次扫描快照和随机令牌。
2. 弹窗默认展示明确选中的待删除聊天，也可切换到全部非保护候选。用户输入包含当前执行数量的确认文字后才能执行。
3. 每条聊天由内容脚本再次检查扫描令牌、聊天 ID、标题、项目归属及手动白名单。全部候选模式还会检查关键词及项目保护；指定删除模式允许覆盖关键词和项目保护。
4. 内容脚本在当前侧栏中定位该聊天，点击其“更多”菜单、删除命令及 ChatGPT 的确认按钮；未能唯一定位控件时停止。
5. 弹窗显示进度，支持在两条聊天之间停止。完成后必须重新获取，以网页当前状态核对剩余聊天。

插件不读取 Cookie 或访问令牌，也不调用 ChatGPT 私有接口。删除只能覆盖本次扫描且当前侧栏仍可定位的条目。删除后无法恢复；页面结构变化时可能跳过或停止。
